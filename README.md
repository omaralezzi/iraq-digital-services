# sifr.one — منصة خدمات رقمية للعراق

موقع ثنائي اللغة لمزوّد خدمات رقمية فردي مقيم في ألمانيا ويستهدف أصحاب الأعمال في العراق. تُختبر التغييرات محليًا قبل تحديث النسخة المنشورة.

## التشغيل

المتطلبات: Node.js 22.13 أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000/ar` للعربية أو `http://localhost:3000/en` للإنجليزية.

## التحقق

```bash
npm run verify
```

يشغّل هذا الأمر فحص TypeScript وESLint والاختبارات وبناء الإنتاج.

## أماكن التعديل الأساسية

- الهوية والاسم والدومين والتواصل والبيانات القانونية: `src/content/siteSettings.ts`
- الخدمات: `src/content/services.ts`
- القطاعات: `src/content/industries.ts`
- الممثلون: `src/content/representatives.ts`
- النماذج التوضيحية: `src/content/demoProjects.ts`
- المسودات والمصادر القانونية: `src/content/legalContent.ts`
- النصوص العامة والمحافظات: `src/content/locales.ts`
- ألوان وتصميم الموقع: `app/globals.css`

## قبل الإطلاق

1. استبدال `[NEW_BUSINESS_EMAIL]` و`[TO_BE_ADDED]`.
2. التحقق من الشكل القانوني وUSt-IdNr. والسجل والجهة الرقابية عند انطباقها.
3. ربط `sifr.one` بالمضيف وتحديث sitemap وrobots والعناوين الأساسية بعد اكتمال الربط.
4. ربط النماذج ببريد أو CRM أو Webhook وتحديد سياسة احتفاظ فعلية.
5. إضافة رقم WhatsApp وتفعيل الأزرار بعد التحقق من طريقة الربط.
6. مراجعة جميع الصفحات القانونية من مختص قبل الإطلاق أو التعاقد.
7. عدم إضافة Analytics أو Marketing قبل إعداد موافقة قانونية فعالة.

لا توجد بيانات عملاء أو ممثلين وهميين، ولا تُرسل النسخة الحالية طلبات إلى خدمات خارجية.
